# Excel Sales Dashboard 📊

## Project Overview
This project is an interactive Sales Dashboard created using Microsoft Excel. It helps analyze sales performance across different regions, products, and salespersons.

The dashboard provides insights into total sales, units sold, and product-wise and region-wise performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Analysis
- Data Visualization

## Dataset Details
The dataset contains sales information, including:
- Date
- Sales Person
- Region
- Product
- Units Sold
- Unit Price
- Cost of Goods
- Total Sales
- Profit

## Dashboard Analysis
The dashboard includes:
- Region-wise Sales Analysis
- Product-wise Sales Analysis
- Salesperson-wise Sales Analysis
- Product-wise Units Sold
- Overall Sales Summary

## Key Insights
- Total Sales: 12,944,500
- Total Units Sold: 4,705
- West region recorded the highest sales.
- Sneakers generated the highest product-wise sales.
- Sales performance can be compared across different regions and salespersons.

## Objective
The objective of this project is to develop practical Excel skills in data cleaning, data analysis, Pivot Tables, formulas, and dashboard creation.
